# Current handoff — 0.4.0

Native Kotlin/Compose app, package dev.rakib.bushra, techwithrakibofficial/JARVIS-AI-Android. Public CI compiles/unit-tests/lints, runs Android 16 UI tests and publishes APK with cached signing key. No local SDK required. No root/ADB/Termux on the user phone.

Current changes: compound command prefix cleanup, null/cancellation suppression and authoritative communication tool results. Stable voice removes parallel ASR and no-match restart loops; optional local AudioRecord/AEC interruption and bounded quiet energy waiting.

AutoChatStore persists explicitly selected recipient+channel rules, purpose, expiry and reply count. IncomingSmsReceiver queues only allowed new messages. BushraNotifications reads WhatsApp non-group MessagingStyle notifications; WhatsAppReplies uses the same notification RemoteInput action. AutoChatWorker uses its own API client and selected provider, checks rules before AI and send, reserves before dispatch, does not retry messages, stops on errors. WorkManager background delays and physical device restrictions remain. Stop means disable rules and cancel work; Activity destruction only stops UI voice. READ_SMS is for explicit named-contact reading; no whole inbox upload. read_messages supports limited SMS/recent WhatsApp notification text, not WhatsApp database history.

Owner explicitly requested opt-in one-time trusted actions and direct messaging; runtime/special Android permissions still require user taps. Default settings preserve this opt-in. Do not claim messages delivered without delivery evidence, all device actions tested, or all bugs solved. CI never contacts a real person. Tests cover routing, auto-rule boundaries, null handling, and UI, not live SIM, notification interoperability, microphone quality or model account access.
